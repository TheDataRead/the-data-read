
# The Data Read: data and code

Every video on **The Data Read** YouTube channel answers one question with public data. This repo holds what you need to check our work.

Each folder is one video:

- `data_table.csv`: every row behind the video, with the numbers used
- `analysis.py`: the exact code that computed every number shown or spoken
- `README.md`: the video's question and data source

Spot an error? Comment on the video and tell us which number and why. If you're right, we'll pin the correction.
