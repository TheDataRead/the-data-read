# The Data Read

**Your questions. Real data. The twist you didn't expect.**

The Data Read is a YouTube channel that answers questions with public data. Every video links its data table and analysis code in this repository, so anyone can check the work.

- YouTube: [@TheDataRead](https://www.youtube.com/@TheDataRead)
- Data and code for each video: [github.com/TheDataRead/the-data-read](https://github.com/TheDataRead/the-data-read)
